# Physical-device recording checklist

Use the latest TestFlight build on the physical iPhone 15 Pro. Turn on Do Not Disturb, hide personal
notifications, and start from the Home Screen. Keep the recording continuous and avoid showing a
personal inbox, password manager, or production credentials.

## Before recording

- [ ] Confirm the iPhone is on the latest available iOS version and record the exact version/build.
- [ ] Install the new Post Streak build from TestFlight.
- [ ] Confirm the demo account is seeded and the secondary friend account remains available.
- [ ] Prepare a disposable account for the deletion flow; do not delete the reviewer demo account.
- [ ] Put Safari on a harmless public URL for the Share Extension demonstration.
- [ ] Confirm the API, privacy, terms, and support URLs load promptly from cellular data.

## Recording order

- [ ] Launch Post Streak from the Home Screen.
- [ ] Show Create account, enter the disposable registration address, submit, and show the email-confirmation message.
- [ ] Switch back to Sign in and log in with the reviewer demo account.
- [ ] Show Home: weekly progress, streak, heatmap, and recent posts.
- [ ] Tap Log a post → Instagram; show the progress and recent-post entry update.
- [ ] Open that post’s ellipsis and delete it.
- [ ] Open Settings; change the display name and weekly target, save, and show Support, Privacy, and Terms links.
- [ ] Open Friends → Manage Friends; show the friend code and request/accept/remove controls.
- [ ] Return to the feed; open a post’s visible ellipsis, submit a report, then block a different seeded friend.
- [ ] Open Safari, Share a URL, choose Log to Post Streak, and finish the Share Extension flow.
- [ ] Return to Post Streak and refresh Home so the shared link appears.
- [ ] Sign out and sign back in once.
- [ ] Sign into the disposable deletion account, open Settings, and complete Delete account and data.
- [ ] End after the app returns to the sign-in screen.

## Before attaching

- [ ] Watch the entire video once with sound off.
- [ ] Verify no personal notifications, emails, passwords, tokens, or unrelated apps are visible.
- [ ] Use a clear filename such as `Post-Streak-App-Review-iPhone15Pro-iOS26.6.mov`.
- [ ] Attach it to the existing App Review conversation and mention it in App Review Information → Notes.
